📐 尺寸链分析工具使用说明书

第一章 工具概述

1.1 什么是尺寸链分析

尺寸链分析是机械设计和制造过程中的重要分析方法，用于计算封闭环与组成环之间的尺寸关系。通过分析尺寸链，可以：

  • 验证零件装配后的最终尺寸是否满足设计要求
  • 合理分配各组成环的公差
  • 预测装配后的合格率
  • 优化设计方案，降低成本

1.2 工具功能特点

  • 图形化标注：支持在二维图纸上直接标注尺寸链
  • 多种计算方法：支持极值法和统计法两种计算方式
  • 轴孔配合分析：专门的轴孔配合计算功能，支持"是否有利"设置
  • X设计值管理：可输入设计要求的X值范围，自动计算CPK
  • 数据导出导入：支持项目数据的保存和加载
  • 结果可视化：清晰的计算结果展示，含CPK过程能力指数
  • 便捷操作：支持鼠标中键拖动、滚轮缩放等快捷操作

第二章 界面说明

2.1 主界面布局

工具界面采用三栏布局：

  • 左侧面板：图像上传、标注控制、标注点列表、尺寸链信息
  • 中间区域：图纸预览和标注操作区，支持缩放和拖动
  • 右侧面板：尺寸代号输入（X设计值、A/B/C...、轴孔尺寸）、计算结果和导出功能

2.2 标注点类型

类型 颜色 说明 编号规则
普通/起止点 🔵 蓝色 尺寸链的起点和终点 S（起点）→ 2,3... → E（终点）
轴孔点 🟢 绿色 轴孔配合位置 1, 2, 3... 顺序编号，显示"轴"字
⚠️ 重要提示

普通点（S/E系列）和轴孔点（数字系列）使用独立的编号系统。普通点从S开始，轴孔点从1开始，各自顺序编号。

第三章 操作指南

3.1 基本操作流程

1
上传图纸

点击左侧面板"点击上传图像"区域，选择需要分析的二维图纸图片（支持 JPG、PNG 格式）。或将图片直接拖拽到上传区域。

2
设置项目名称

在图像预览区域顶部的输入框中填写"项目+零件名称"，这将用于导出文件的命名。

3
选择链方向

在左侧面板选择链方向：X向（水平）或 Y向（垂直）。这将决定尺寸链的计算方向。

4
选择标注类型

选择标注类型：
• 普通/起止：用于标注尺寸链的起点S和终点E
• 轴孔：用于标注轴孔配合位置

5
标注尺寸点

在图纸上点击需要标注的位置。普通点按S→2→3→...→E的顺序，轴孔点按1→2→3→...的顺序。

6
生成尺寸链

点击"✨ 生成"按钮，自动生成尺寸链信息。此时会在图纸上绘制尺寸线（红色）和延长线（蓝色虚线）。

7
输入X设计值

在右侧面板最上方，输入X设计值的较小值和较大值（格式：较小值 ~ 较大值）。这是设计要求的封闭环范围。

8
输入各段尺寸

输入A、B、C...各段的：基本尺寸、公差、CPK值、备注。对于轴孔尺寸，还需输入D（孔径）和d（轴径）的相关数据。

9
设置轴孔是否有利

对于轴孔配合，在"是否有利"下拉框中选择：
• 是：间隙配合（有利，间隙为正）
• 否：过盈配合（不利，间隙为负）

10
执行计算

点击"📊 计算"按钮，查看极值法和统计法的计算结果，包括公称值、公差、累积偏移和CPK值。

3.2 图像操作技巧

操作 说明
左键点击 在图纸上添加标注点或拖动现有点
中键按住拖动 拖动图纸查看不同区域
滚轮 缩放图纸（以鼠标位置为中心）
+ / - 按钮 放大/缩小图纸
重置 按钮 恢复原始缩放比例

3.3 标注点管理

  • 在"标注点列表"中可查看所有已标注的点
  • 点击"清空"按钮可删除所有标注点
  • 标注点可在图纸上拖动调整位置
  • 使用"显示点"和"显示线"复选框控制标注的显示

第四章 尺寸输入说明

4.1 X设计值（封闭环设计值）

X设计值是设计要求的封闭环尺寸范围，位于尺寸代号区域的最上方：

  • 较小值：封闭环的最小允许值
  • 较大值：封闭环的最大允许值
  • 格式：较小值 ~ 较大值

输入X设计值后，统计法计算结果会显示CPK值，用于评估过程能力。

4.2 普通尺寸（A、B、C...）

参数 说明 示例
基本尺寸 该段的公称尺寸值 50.00
公差 尺寸公差值（±值） 0.05
CPK 过程能力指数（默认1.0） 1.33
备注 尺寸的中文名称或说明 轴承外径
正负号 绿色+表示增环，红色-表示减环 + 或 -

4.3 轴孔尺寸（D1/d1、D2/d2...）

每个轴孔包含以下参数：

参数 说明
D（大写） 孔径尺寸：基本尺寸、公差、CPK、备注
d（小写） 轴径尺寸：基本尺寸、公差、CPK、备注
是否有利 间隙配合选"是"，过盈配合选"否"
💡 提示

轴孔间隙 = D（孔径）- d（轴径）。间隙配合时间隙为正（有利），过盈配合时间隙为负（不利）。

第五章 计算方法说明

5.1 极值法（完全互换法）

极值法假设所有组成环同时处于极限状态，是最保守但最可靠的计算方法。

封闭环公称值：N₀ = Σ(增环) - Σ(减环) + Σ(轴孔间隙)

公差累积：T₀ = Σ(普通尺寸公差) + Σ(轴孔公差)/2

左极限：= 公称值 - 公差 - 累积偏移
右极限：= 公称值 + 公差 + 累积偏移

5.2 统计法（概率法）

统计法基于概率统计原理，假设尺寸服从正态分布，可以获得更宽松的公差要求。

单方差：σ² = (公差 / (3 × CPK))²

整体方差：σ₀ = √(Σσ²)

最终公差：T₀ = 4.5 × σ₀

左极限：= 公称值 - 公差 - 累积偏移
右极限：= 公称值 + 公差 + 累积偏移

5.3 CPK计算（过程能力指数）

当输入X设计值后，统计法会计算CPK值：

CPK1 = (X设计值较大值 - X公称值 - 累积偏移) / (3 × 整体方差)

CPK2 = (X公称值 - 累积偏移 - X设计值较小值) / (3 × 整体方差)

CPK = min(CPK1, CPK2)
CPK值 颜色 过程能力评估
≥ 1.33 🟢 绿色 过程能力充足，合格率高
1.0 ~ 1.33 🟡 黄色 过程能力尚可，需注意监控
< 1.0 🔴 红色 过程能力不足，需要改进

5.4 增环与减环判定

  • 增环（+）：该尺寸增大时，封闭环也增大（绿色显示）
  • 减环（-）：该尺寸增大时，封闭环减小（红色显示）
  • 判定方法：根据标注点的坐标自动判断，从起点到终点，同向为增环，反向为减环

第六章 数据管理

6.1 导出数据

点击"导出数据"按钮，将保存包含以下内容的JSON文件：

  • 项目信息（名称、方向等）
  • 原始图像数据（Base64编码）
  • 标注点坐标和类型
  • 所有尺寸数据（含X设计值、CPK等）
  • 计算结果

文件名格式：项目名称_链方向.json

6.2 导出图像

点击"导出图像"按钮，将保存带有标注的图纸图片（PNG格式），方便存档和分享。

6.3 加载数据

点击"📂 加载数据"按钮，选择之前导出的JSON文件，即可恢复完整的项目状态，包括图纸、标注、尺寸数据和计算结果。

💡 提示

导出文件包含完整图像数据，文件可能较大。建议定期导出数据备份，并按项目分类管理导出文件。

第七章 注意事项

7.1 标注注意事项

  • 普通点必须按S→...→E的顺序标注，且至少需要2个点才能形成封闭环
  • 轴和孔的标注相互独立，编号各自从1开始
  • 标注点位置应准确对应图纸上的特征位置
  • 生成尺寸链后，蓝色虚线延长线会自动连接到对应的尺寸线

7.2 计算注意事项

  • 确保所有尺寸数据都已正确输入
  • X设计值的较小值应小于或等于较大值
  • 极值法结果更保守，统计法结果更宽松
  • 建议关键尺寸使用极值法验证，一般尺寸可用统计法优化公差
  • CPK值≥1.33表示过程能力充足

7.3 浏览器兼容性

  • 推荐使用 Chrome、Edge、Firefox 等现代浏览器
  • 需要支持 HTML5 Canvas 和 File API
  • 建议使用 1920×1080 或更高分辨率以获得最佳体验

第八章 常见问题

Q1：为什么计算结果显示"请至少标注2个点"？

A：尺寸链分析需要至少一个起点(S)和一个终点(E)才能形成封闭环。请确保已标注S和E两个点，并点击"生成"按钮。

Q2：如何修改已经输入的尺寸数据？

A：直接在右侧面板的输入框中修改数值即可。修改后需要重新点击"计算"按钮更新结果。

Q3：轴和孔的编号为什么会重复？

A：这是正常设计。普通点（S/E系列）和轴孔点（数字系列）使用独立的编号系统，各自从1（或S）开始编号，互不影响。

Q4：导入数据后图纸显示不正常？

A：请确保导入的JSON文件是由本工具导出的完整数据文件，且文件未被修改或损坏。导出文件包含图像数据，文件较大是正常的。

Q5：CPK值显示为负数或很大？

A：请检查：1）X设计值的较小值和较大值是否输入正确；2）各段尺寸数据是否合理；3）轴孔的"是否有利"设置是否正确。

Q6：如何清空所有数据重新开始？

A：点击左侧面板的"清空"按钮可删除所有标注点，然后可以重新标注。如需完全重置，可刷新页面。

Q7：图像预览区域如何滚动查看？

A：使用鼠标中键按住拖动可以平移图纸，使用滚轮可以缩放。也可以使用+/-按钮和滚动条。

💡 使用建议

建议在开始分析前先规划好尺寸链的走向和标注顺序，这样可以提高工作效率。对于复杂的尺寸链，可以先在纸上画出简图，明确各环的增减性质。定期导出数据备份，防止意外丢失。
